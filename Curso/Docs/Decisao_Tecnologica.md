# Decisao tecnologica - Reserva de Ingressos (Flash Booking)

## Estrutura do workspace

- **Workspace:** Cielo
- **Codigo da aplicacao:** pasta `Codigo/backend`
- **Avaliacao independente:** pasta `Avaliacao`

## Stack tecnologica

- **Backend:** Java 21 e Spring Boot; Lombok nao e utilizado.
- **Arquitetura:** camadas controller, DTO, service, repository e model.
- **Persistencia:** MySQL com JPA/Hibernate e migrations Flyway.
- **Execucao local:** Docker Compose.
- **Validacao:** testes Maven automatizados e Harness independente.

O desafio atual e backend-only. Frontend, Node.js, TypeScript, HTML, CSS, IA e pagamento nao fazem parte do produto.
